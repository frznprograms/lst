# lst

A better way to use `ls` in my shell.

## Core Idea

The `ls` command is powerful but in large directories it can be unsatisfying or even challenging to view all the contents of a project at a glance. Many alternatives exist such as `tree` (see [here](https://github.com/peteretelej/tree)) and `eza` (see [here](https://github.com/eza-community/eza)). This project is *not* meant to be a replacement for those, rather it's my opinionated take on what I'd like my `lst` command to show me.

Heavily inspired by the `nushell` variant of `ls`.
